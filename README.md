## Algoritma Tugas Persamaan Kuadrat

1. Memasukkan nilai koefisien a, b, dan c.
2. Memeriksa apakah nilai a sama dengan 0.
3. Jika a sama dengan 0, maka input bukan persamaan kuadrat.
4. Jika a tidak sama dengan 0, menghitung diskriminan dengan rumus D = b² - 4ac.
5. Jika D lebih besar dari 0, maka terdapat dua akar real berbeda.
6. Jika D sama dengan 0, maka terdapat satu akar real kembar.
7. Jika D kurang dari 0, maka tidak terdapat akar real.
